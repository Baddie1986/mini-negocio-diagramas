2. Diagrama de Flujo de Procesos

Secuencia lógica que sigue un cliente desde que abre la aplicación hasta que contacta al vendedor.

flowchart TD A([Inicio: Cliente abre la App]) --> B{¿Tiene sesión iniciada?} B -- No --> C[Registrarse o Iniciar Sesión] C --> D B -- Sí --> D[Pantalla Principal: Buscador] D --> E[Ingresa palabra clave o selecciona categoría] E --> F[El sistema filtra la Base de Datos NoSQL] F --> G[Muestra lista de mininegocios cercanos] G --> H[Cliente selecciona un negocio] H --> I[Ver detalles, fotos y ubicación] I --> J{¿Le interesa comprar?} J -- No --> D J -- Sí --> K[Clic en botón 'Contactar por WhatsApp'] K --> L[El sistema redirige a la app de WhatsApp] L --> M([Fin: Cierran el trato externamente])
